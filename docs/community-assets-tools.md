# Tool community marks

Retrieved September 27, 2026. These files identify independent discussion communities about the named products. They do not identify official accounts or imply a relationship with the brands.

The eight monochrome marks come from the [Simple Icons collection](https://github.com/simple-icons/simple-icons), pinned to commit `d4e6ba93e48f178898707f0145ec285f28b64b38`. The collection has a [CC0 dedication](https://github.com/simple-icons/simple-icons/blob/d4e6ba93e48f178898707f0145ec285f28b64b38/LICENSE.md), but its [disclaimer](https://github.com/simple-icons/simple-icons/blob/d4e6ba93e48f178898707f0145ec285f28b64b38/DISCLAIMER.md) distinguishes that from individual brand rights. Their metadata does not supply separate icon licenses. Trademark rights remain with the owners. Lovable's asset is provided directly by its official site, with no standalone asset license stated.

Only a fixed fill color was added to the monochrome SVG roots. Their original viewBoxes and path geometry are preserved. Lovable's original gradient artwork is unchanged. The manifest supplies contrasting circular backgrounds for the UI. All nine assets are bundled locally, remain below 8 KB individually, and contain no scripts, event handlers, foreign objects, embedded images, or external references. Lovable uses internal gradient and clipping references only. No browser request to a brand server or icon service is required.
