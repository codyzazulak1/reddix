## Visual and safety notes

- Claude Code uses its dedicated pixel mascot, distinct from Anthropic's A mark.
- Codex intentionally reuses its parent OpenAI blossom. It is not a fabricated Codex-specific mark.
- Single-color Simple Icons paths are unchanged, with fixed foreground colors selected for readable light or dark tiles. These are monochrome display treatments, not claims of exact official color specifications.
- The white OpenAI blossom path is unchanged. Its viewport is normalized around the artwork with padding; its aspect ratio is retained. It is displayed on a dark tile.
- Grok retains the official favicon's two white mark paths. The favicon's background, duplicate outline, mask, blur effects, and foreignObject were removed. Its original square viewBox is retained.
- Every bundled SVG contains only `svg` and `path` elements, with fixed path/fill/viewBox attributes. There are no scripts, event handlers, embedded HTML, remote resources, fonts, or runtime logo-service requests.
- All source files are small vectors, from 213 bytes to approximately 3 KB. Assets are served locally and remain available if an upstream site changes.
- Grok's favicon does not advertise an open-source license. It is retained as third-party brand artwork for identification. OpenAI's repository is MIT-licensed, with its notice reproduced below; OpenAI brand usage terms still apply to its marks.
